# Delegate downloads

Public landing page and developer-preview downloads for Delegate, a native macOS workspace for personal tasks and AI agents. Application source is maintained separately.

The site uses plain HTML, CSS and JavaScript. Serve this directory with a static web server; no build step is needed. GitHub Pages publishes the `main` branch root.

Preview downloads are ad-hoc signed, not Apple-notarized. See each release for requirements, limitations and checksums. The app is not PRD-complete.
